# HEH-Shop

The Launchpad Shop, at **shop.civilinitiatives.org**: everything you can put on your
Homework Launchpad profile picture - over a thousand items across six character
styles, emoji characters, backgrounds, patterns, frames, hats, stickers, name
colours and dashboard themes.

- **Rarity:** Common, Rare, Epic, Legendary and Mythic. Mythic items are limited
  (only so many copies ever) and only on sale in the weeks they're in the weekly shop.
- **Prices:** ⭐ Level Up points for most things; 🪙 Launchpad Pounds (earned by getting
  answers right in any learning game) for the rarest.
- **Earned, never sold:** some items only come from achievements; helpers have
  their own items while they're helpers; a few are one of a kind.
- Every card shows how many people own it.

Prices, stock, the weekly shop and what you own all live on the server (the
`profile` function); this page only shows them. Pictures are drawn by
`avatar.js` on the main site.
